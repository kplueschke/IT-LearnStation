Vorwärtskalkulation

Das vollständige Kalkulationsschema vom Listeneinkaufspreis bis zum Bruttoverkaufspreis.

Das Kalkulationsschema

Listeneinkaufspreis (LEP) 100%
- Liefererrabatt % vom LEP
= Zieleinkaufspreis (ZEP) 100%
- Lieferskonto % vom ZEP
= Bareinkaufspreis (BEP)
+ Bezugskosten (Fracht, Porto, Verpackung) Betrag
= Bezugspreis (Einstandspreis) 100%
+ Handlungskostenzuschlag (HKZ) % vom Bezugspreis
= Selbstkostenpreis (SKP) 100%
+ Gewinnzuschlag % vom SKP
= Barverkaufspreis (BVP) 97% / 98% (entspricht 100% - Skonto)
+ Kundenskonto % (berechnet im Hundert)
= Zielverkaufspreis (ZVP) z.B. 90% (entspricht 100% - Rabatt)
+ Kundenrabatt % (berechnet im Hundert)
= Nettoverkaufspreis / Listenverkaufspreis (LVP) 100%
+ Umsatzsteuer (MwSt) 19% vom Nettoverkaufspreis
= Bruttoverkaufspreis 119%

Besonderheit: "Im Hundert" rechnen

Bei der Berechnung des Verkaufsbereichs von unten (ausgehend vom Barverkaufspreis zum Nettoverkaufspreis) muss man beachten, dass die prozentualen Abzüge (Skonto, Rabatt) vom jeweils nächsten, höheren Wert (100%) berechnet werden.

Wenn der Barverkaufspreis vorliegt und 2% Skonto gewährt werden, entspricht der Barverkaufspreis 98%. Der Zielverkaufspreis (100%) wird berechnet durch: (Barverkaufspreis / 98) * 100.
