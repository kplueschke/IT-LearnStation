IPv6 Grundlagen

Aufbau, Komprimierung und Netzaufteilung von IPv6-Adressen.

Aufbau einer IPv6-Adresse

Eine IPv6-Adresse ist 128 Bit lang. Sie wird in 8 Blöcken (Hextets) zu je 16 Bit (4 Hexadezimalzeichen) geschrieben, getrennt durch Doppelpunkte.

2001 : 0db8 : 85a3 : 0000 : 0000 : 8a2e : 0370 : 7334

Komprimierungsregel 1: Führende Nullen

Führende Nullen innerhalb eines 16-Bit-Blocks dürfen weggelassen werden. Ein Block, der nur aus Nullen besteht, wird als einzelne "0" geschrieben.

0db8 → db8
0000 → 0

Komprimierungsregel 2: Null-Blöcke

Eine fortlaufende Folge von Blöcken, die nur aus Nullen bestehen, kann einmalig pro Adresse durch zwei Doppelpunkte (::) ersetzt werden.

Unkomprimiert:

2001:db8:0:0:0:0:2:1

↓

2001:db8::2:1

Netz- und Interface-Identifier (Prefix)

Ähnlich wie bei IPv4 wird die Adresse in einen Netzteil (Routing-Präfix + Subnetz-ID) und einen Hostteil (Interface-Identifier) aufgeteilt. Bei IPv6 wird üblicherweise ein /64 Präfix verwendet.

2001:0db8:85a3:0000
0000:8a2e:0370:7334
Netzpräfix (64 Bit)
Interface ID (64 Bit)

Bei einem /64 Präfix gehören die ersten 4 Hextets zum Netzwerk, die letzten 4 zum Endgerät.

Global Unicast (2000::/3)

Weltweit eindeutig und routbar (vergleichbar mit öffentlichen IPv4-Adressen). Beginnen oft mit 2001: oder 2a00:.

Link-Local (fe80::/10)

Nur im lokalen Netzwerk gültig, nicht im Internet routbar (vergleichbar mit APIPA/169.254.).

Unique Local (fc00::/7)

Für private Netzwerke (vergleichbar mit privaten IPv4-Adressen wie 192.168.x.x).
