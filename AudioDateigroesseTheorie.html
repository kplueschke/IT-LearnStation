Audio-Dateigrößen

Berechnung des Speicherbedarfs von unkomprimierten Audiodaten (z.B. WAV).

Einflussfaktoren

  • Abtastrate (Sampling-Rate): Gibt an, wie oft das analoge Signal pro Sekunde abgetastet wird (in Hertz, Hz). CD-Qualität: 44.100 Hz (44,1 kHz). Studio: 48 kHz oder 96 kHz.
  • Auflösung (Wortbreite/Sampling-Tiefe): Anzahl der Bits pro Abtastwert. Bestimmt den Dynamikumfang. CD-Qualität: 16 Bit. Studio: 24 Bit oder 32 Bit.
  • Kanäle (Channels): Mono (1 Kanal), Stereo (2 Kanäle), Surround (z.B. 5.1 = 6 Kanäle).
  • Dauer: Die Länge der Audiodatei in Sekunden.

Formeln

Gesamtgröße in Bit

Größe = Rate [Hz] * Auflösung [Bit] * Kanäle * Dauer [s]

Bitrate (in Bit/s)

Bitrate = Rate [Hz] * Auflösung [Bit] * Kanäle

Umrechnung in Megabyte (MB)

MB = Bit / 8 / 1024 / 1024

Beispielrechnung

Ein Song (Dauer: 3 Minuten und 30 Sekunden) wird unkomprimiert in CD-Qualität (44,1 kHz, 16 Bit, Stereo) gespeichert. Wie groß ist die Datei in Megabyte (MB)?

  1. Dauer in Sekunden: (3 * 60) + 30 = 210 Sekunden
  2. Abtastrate in Hz: 44.100 Hz
  3. Größe in Bit: 44.100 Hz * 16 Bit * 2 Kanäle * 210 Sekunden
  4. Berechnung (Bit): 296.352.000 Bit
  5. In Byte ( / 8): 37.044.000 Byte
  6. In KB ( / 1024): 36.175,78 KB
  7. In MB ( / 1024): ≈ 35,33 MB
