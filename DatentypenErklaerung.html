Datentypen & Parameter

Werttypen vs. Referenztypen und das Prinzip der Parameterübergabe (Call-by-Value vs. Call-by-Reference).

Werttypen vs. Referenztypen

Werttypen

Bei Werttypen wird der eigentliche Wert direkt im Speicher abgelegt (meistens auf dem Stack). Wenn eine Variable einem Werttyp zugewiesen wird, erhält sie eine eigene Kopie der Daten.

  • Beispiele: int, float, bool, char
  • Zuweisung a = b kopiert den Wert. Änderungen an a betreffen b nicht.

Referenztypen

Bei Referenztypen speichert die Variable nicht die Daten selbst, sondern nur einen Verweis (eine Speicheradresse / Zeiger) auf den Ort, an dem die Daten liegen (meistens auf dem Heap).

  • Beispiele: Klassen, Arrays, Strings (oftmals), Objekte
  • Zuweisung a = b kopiert nur die Referenz. Beide Variablen zeigen auf dasselbe Objekt im Speicher!

Call-by-Value (Werteübergabe)

Wird eine Variable "by Value" an eine Funktion übergeben, so erhält die Funktion eine Kopie des Wertes. Änderungen an der Variable innerhalb der Funktion haben keine Auswirkungen auf die ursprüngliche Variable außerhalb der Funktion.

C++
void verdopple(int x) {
    x = x * 2;  // Ändert nur die lokale Kopie
}

int main() {
    int zahl = 5;
    verdopple(zahl);
    // zahl ist hier immer noch 5!
}

Call-by-Reference (Referenzübergabe)

Wird eine Variable "by Reference" übergeben, erhält die Funktion die Speicheradresse der originalen Variable. Dadurch arbeitet die Funktion direkt mit dem Original. Änderungen, die innerhalb der Funktion gemacht werden, sind auch außerhalb sichtbar.

C++
void verdopple(int& x) {
    // x ist eine Referenz (&)
    x = x * 2;
}

int main() {
    int zahl = 5;
    verdopple(zahl);
    // zahl ist hier jetzt 10!
}
C#
void Verdopple(ref int x) {
    // Schlüsselwort 'ref'
    x = x * 2;
}

void Main() {
    int zahl = 5;
    Verdopple(ref zahl);
    // zahl ist hier jetzt 10!
}
