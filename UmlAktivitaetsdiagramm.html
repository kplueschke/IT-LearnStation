UML Aktivitätsdiagramm Elemente

Eine Übersicht über die wichtigsten grafischen Elemente, aus denen ein UML-Aktivitätsdiagramm aufgebaut ist.

Startknoten (Initial Node)

Kennzeichnet den Beginn eines Aktivitätsdiagramms. Es ist der Einstiegspunkt in den Ablauf.

Wird als vollständig ausgefüllter, schwarzer (bzw. einfarbiger) Kreis dargestellt.

Endknoten (Final Node)

Kennzeichnet das Ende des gesamten Ablaufs. Wenn dieser Knoten erreicht wird, stoppt die gesamte Aktivität.

Wird als ausgefüllter Kreis mit einer zusätzlichen, äußeren Umrandung ("Bullseye") dargestellt.

Aktion (Action)

Stellt einen elementaren Schritt oder eine atomare Aufgabe innerhalb des Ablaufs dar, die ausgeführt wird.

Wird als abgerundetes Rechteck gezeichnet, in dem die Beschreibung der Aktion steht.

Entscheidung / Verzweigung (Decision Node)

Spaltet den Kontrollfluss basierend auf einer Bedingung (Guard) auf. Nur ein Pfad kann weiterverfolgt werden.

Wird als Raute gezeichnet. Die abgehenden Pfade haben meist Bedingungen in eckigen Klammern [ ].

Gabelung / Vereinigung (Fork / Join)

Erlaubt parallele Abläufe. Eine Gabelung (Fork) spaltet den Fluss in mehrere parallele Fäden auf, eine Vereinigung (Join) wartet, bis alle parallelen Fäden ankommen.

Wird als dicker, ausgefüllter schwarzer Balken (horizontal oder vertikal) gezeichnet.

Kontrollfluss (Control Flow)

Zeigt die zeitliche und logische Reihenfolge an, in der Aktionen ausgeführt werden.

Wird als durchgehender Pfeil mit offener Spitze gezeichnet.
