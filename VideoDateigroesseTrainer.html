Video-Dateigrößen Trainer

Übe das Berechnen der Dateigröße von unkomprimierten Videodaten

Formeln

  • Pixel pro Frame:
    Breite * Höhe
  • Dateigröße pro Frame (Bit):
    Pixel pro Frame * Farbtiefe
  • FPS (Frames Per Second):
    Bilder pro Sekunde
  • Dauer in Sekunden:
    Minuten * 60 + Sekunden
  • Dateigröße gesamt (Bit) =
    Dateigröße/Frame * FPS * Dauer (s)
  • Umrechnung in GiB:
    Bit / 8 / 1024 / 1024 / 1024
