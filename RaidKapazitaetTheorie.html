RAID-Kapazitäten

Berechnung der nutzbaren Netto-Kapazität verschiedener RAID-Level.

Grundregel für Festplattengrößen

In einem RAID-Verbund bestimmt immer die kleinste Festplatte die nutzbare Kapazität pro Platte. Wenn man z.B. eine 2 TB und eine 4 TB Festplatte in einem RAID kombiniert, werden von der 4 TB Platte nur 2 TB genutzt. Die restlichen 2 TB liegen brach.

c = Kapazität der kleinsten Festplatte

n = Anzahl der Festplatten im Verbund

RAID 0 (Striping)

Daten werden auf alle Platten verteilt (schneller). Keine Redundanz! Fällt eine Platte aus, sind alle Daten weg.

Nutzbare Kapazität:

Kapazität = n * c

Mindestens 2 Festplatten.

RAID 1 (Mirroring)

Daten werden komplett gespiegelt. Sehr sicher, aber "verschwendet" 50% des Speichers.

Nutzbare Kapazität:

Kapazität = (n / 2) * c

Gerade Anzahl an Festplatten (min. 2).

RAID 5 (Parity)

Guter Kompromiss aus Speed, Speicherplatz und Sicherheit. Eine Festplatte darf ausfallen (Paritätsdaten).

Nutzbare Kapazität:

Kapazität = (n - 1) * c

Mindestens 3 Festplatten.

RAID 6 (Dual Parity)

Wie RAID 5, aber es dürfen zwei Festplatten gleichzeitig ausfallen. Höhere Sicherheit.

Nutzbare Kapazität:

Kapazität = (n - 2) * c

Mindestens 4 Festplatten.

RAID 10 (1+0)

Kombiniert die Geschwindigkeit von RAID 0 (Striping) mit der Sicherheit von RAID 1 (Mirroring). Sehr performant, aber teuer (50% Verlust).

Nutzbare Kapazität:

Kapazität = (n / 2) * c

Gerade Anzahl an Festplatten (min. 4).

Beispielrechnung

Ein Server wird mit fünf Festplatten (3x 4 TB, 2x 2 TB) ausgestattet. Wie groß ist die nutzbare Netto-Kapazität, wenn ein RAID 5 konfiguriert wird?

  1. Anzahl Festplatten (n): 5
  2. Kleinste Kapazität (c): 2 TB (Die 4 TB Platten werden "beschnitten")
  3. Formel RAID 5: (n - 1) * c
  4. Rechnung: (5 - 1) * 2 TB
  5. Ergebnis: 4 * 2 TB = 8 TB
