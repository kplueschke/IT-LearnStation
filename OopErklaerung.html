OOP Grundlagen

Die wichtigsten Konzepte der Objektorientierten Programmierung (OOP) anhand von Beispielen in C#.

Klassen und Objekte

Eine Klasse ist der Bauplan oder die Schablone, die Eigenschaften (Attribute) und Verhalten (Methoden) definiert. Ein Objekt (Instanz) ist die konkrete Umsetzung dieses Bauplans im Speicher. 

// Die Klasse (Bauplan)
class Auto
{
    public string Marke; // Attribut
    public void Hupen()  // Methode
    {
        Console.WriteLine("Tuut!");
    }
}

// Die Nutzung (Objekte/Instanzen)
Auto meinAuto = new Auto();
meinAuto.Marke = "VW";
meinAuto.Hupen();

Kapselung (Encapsulation)

Daten (Attribute) werden vor unberechtigtem Zugriff geschützt. Der Zugriff erfolgt nur über definierte Schnittstellen (Methoden oder in C# Properties/Getter und Setter). Dies schützt den internen Zustand des Objekts. Sichtbarkeiten (Access Modifier): public (jeder), private (nur die Klasse selbst), protected (Klasse und abgeleitete Klassen). 

class Bankkonto
{
    // private: Von außen nicht direkt änderbar
    private decimal kontostand;

    // public Property: Kontrollierter Zugriff
    public decimal Kontostand
    {
        get { return kontostand; }
        private set { kontostand = value; } // Setzen nur intern
    }

    public void Einzahlen(decimal betrag)
    {
        if(betrag > 0) kontostand += betrag;
    }
}

Vererbung (Inheritance)

Eine neue Klasse (Kindklasse) übernimmt Attribute und Methoden einer existierenden Klasse (Elternklasse/Basisklasse). Das fördert die Wiederverwendbarkeit von Code ("Is-A" Beziehung). 

class Tier // Basisklasse
{
    public void Atmen() { Console.WriteLine("Atmet..."); }
}

// Hund erbt von Tier (nutzt den Doppelpunkt :)
class Hund : Tier
{
    public void Bellen() { Console.WriteLine("Wuff!"); }
}

Hund meinHund = new Hund();
meinHund.Atmen(); // Geerbt von Tier
meinHund.Bellen(); // Eigene Methode

Polymorphie (Vielgestaltigkeit)

Objekte verschiedener Klassen können über eine gemeinsame Basisklasse oder ein Interface auf die gleiche Weise angesprochen werden. Eine geerbte Methode kann von der Kindklasse überschrieben werden, um ein eigenes Verhalten zu definieren (Overriding). 

class Figur
{
    // 'virtual' erlaubt das Überschreiben
    public virtual void Zeichnen() { Console.WriteLine("Zeichne Figur"); }
}

class Kreis : Figur
{
    // 'override' ersetzt das Verhalten
    public override void Zeichnen() { Console.WriteLine("Zeichne Kreis"); }
}

Figur f = new Kreis();
f.Zeichnen(); // Ruft "Zeichne Kreis" auf!

Struct vs. Class

Ein struct (Werttyp) wird im Stack gespeichert. Bei Zuweisung wird eine Kopie erstellt. Eine class (Referenztyp) wird im Heap gespeichert. Bei Zuweisung wird nur der Verweis (Pointer) kopiert. Structs eignen sich für kleine Datenstrukturen (z.B. Koordinaten, Vektoren), Klassen für komplexe Objekte. 

struct Punkt
{
    public int X;
    public int Y;
}

Punkt p1 = new Punkt { X = 10, Y = 20 };
Punkt p2 = p1; // p2 ist eine Kopie
p2.X = 50;     // p1.X bleibt 10 (Werttyp!)

class Person
{
    public string Name;
}

Person pers1 = new Person { Name = "Alice" };
Person pers2 = pers1; // pers2 zeigt auf dasselbe Objekt
pers2.Name = "Bob";   // pers1.Name ist jetzt auch "Bob" (Referenztyp!)
