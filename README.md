💻 IT-LearnStation
A private, interactive web platform designed to accelerate learning and master core software engineering and networking concepts. Built specifically to support the journey of becoming a Fachinformatiker für Anwendungsentwicklung (FIAE).

The goal of this platform is to bridge theoretical vocational school knowledge with practical, hands-on web applications.

🚀 Features & Tools
🌐 Networking Modules
IPv4 Trainer: An interactive tool to master subnetting, CIDR notation, network/broadcast address calculations, and host ranges.

IPv6 Trainer: Practice shortening addresses, expanding notation, and understanding hex-based subnetting structures.

🛠️ Planned Enhancements
More interactive micro-tools covering database normalization (1NF to 3NF).

Logic gate simulators and boolean algebra trainers.

CS@School curriculum-aligned quizzes and flashcards.

🛠️ Tech Stack
Frontend: HTML5, CSS3, Modern JavaScript

Design Philosophy: Minimalism, distraction-free UI, and highly responsive components for seamless learning on both desktop and mobile.
