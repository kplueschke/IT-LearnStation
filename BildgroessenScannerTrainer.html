Bildgrößen & Scanner Trainer

Übe das Berechnen von Pixelauflösung und Dateigröße bei Scannern (DPI)

Formeln

  • 1 Zoll (Inch) = 2,54 cm
  • Breite in Zoll = Breite (cm) / 2,54
  • Höhe in Zoll = Höhe (cm) / 2,54
  • Pixel (Breite) = Breite (Zoll) * DPI
  • Pixel (Höhe) = Höhe (Zoll) * DPI
  • Megapixel = Gesamtpixel / 1.000.000
  • Gesamtpixel = Pixel (B) * Pixel (H)
  • Dateigröße (Bit) = Gesamtpixel * Farbtiefe (Bit)
  • Byte = Bit / 8
  • KiB = Byte / 1024
  • MiB = KiB / 1024
  • Bilderanzahl = Speicher (MiB) / Dateigröße (MiB)
