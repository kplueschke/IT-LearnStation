Audio-Dateigrößen Trainer

Übe das Berechnen der Dateigröße von unkomprimierten Audiodaten

Formeln

  • Abtastrate (Sampling-Rate):
    z.B. 44,1 kHz = 44.100 Hz = 44.100 Samples pro Sekunde
  • Auflösung:
    Bit pro Sample (z.B. 16 Bit)
  • Kanäle:
    Mono = 1 Kanal, Stereo = 2 Kanäle
  • Dauer in Sekunden:
    Minuten * 60 + Sekunden
  • Dateigröße (Bit) =
    Abtastrate * Auflösung * Kanäle * Dauer (s)
  • Umrechnung in MiB:
    Bit / 8 / 1024 / 1024
