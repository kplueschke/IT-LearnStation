SQL Basics (Theorie)

SQL (Structured Query Language) ist die Standardsprache zur Kommunikation mit relationalen Datenbanken. Hier findest du alle grundlegenden Befehle und Konzepte als Nachschlagewerk.

Datenmanipulation (DML)

SELECT

Liest Daten aus einer oder mehreren Tabellen. 

SELECT spalte1, spalte2
FROM tabellenname;

-- Alle Spalten auswählen:
SELECT * FROM kunden;

INSERT INTO

Fügt neue Datensätze in eine Tabelle ein. 

INSERT INTO tabellenname (spalte1, spalte2)
VALUES ('wert1', 'wert2');

UPDATE

Ändert bestehende Datensätze in einer Tabelle. 

UPDATE tabellenname
SET spalte1 = 'neuer_wert'
WHERE bedingung;

DELETE

Löscht Datensätze aus einer Tabelle. 

DELETE FROM tabellenname
WHERE bedingung;

Filtern & Sortieren

WHERE

Filtert Datensätze, die eine bestimmte Bedingung erfüllen. 

SELECT * FROM mitarbeiter
WHERE gehalt > 3000 AND abteilung = 'IT';

-- Operatoren: =, <>, >, <, >=, <=, LIKE, IN, BETWEEN

ORDER BY

Sortiert das Resultat nach einer oder mehreren Spalten. 

SELECT * FROM kunden
ORDER BY nachname ASC, vorname DESC;
-- ASC: Aufsteigend (Standard), DESC: Absteigend

Aggregieren & Gruppieren

Aggregatfunktionen

Führen eine Berechnung an einer Menge von Werten durch und geben einen einzelnen Wert zurück. 

COUNT(spalte) -- Zählt die Anzahl der Zeilen
SUM(spalte)   -- Summiert die Werte
AVG(spalte)   -- Berechnet den Durchschnitt
MIN(spalte)   -- Findet den kleinsten Wert
MAX(spalte)   -- Findet den größten Wert

GROUP BY & HAVING

Fasst Zeilen mit gleichen Werten in Zeilengruppen zusammen. HAVING filtert Gruppen (wie WHERE für Zeilen). 

SELECT abteilung_id, COUNT(*) AS anzahl_mitarbeiter
FROM mitarbeiter
GROUP BY abteilung_id
HAVING COUNT(*) > 5;

Tabellen verknüpfen (JOIN)

INNER JOIN

Gibt Datensätze zurück, die in beiden Tabellen übereinstimmende Werte haben. 

SELECT m.vorname, a.name
FROM mitarbeiter m
JOIN abteilungen a ON m.abteilung_id = a.id;

LEFT (OUTER) JOIN

Gibt alle Datensätze aus der linken Tabelle und die übereinstimmenden aus der rechten Tabelle zurück (sonst NULL). 

SELECT m.vorname, a.name
FROM mitarbeiter m
LEFT JOIN abteilungen a ON m.abteilung_id = a.id;
