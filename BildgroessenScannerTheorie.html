Bildgrößen (DPI) & Scanner

Grundlagen zur Berechnung von Pixelauflösung und Dateigrößen beim Scannen.

Grundlagen

  • DPI (Dots per Inch): Gibt an, wie viele Bildpunkte (Pixel) pro Inch gescannt bzw. gedruckt werden.
  • 1 Inch (Zoll): Entspricht exakt 2,54 cm.
  • Farbtiefe: Bestimmt, wie viele Bits für die Farbinformation eines einzelnen Pixels verwendet werden.
    • Schwarzweiß (Strichzeichnung): 1 Bit
    • Graustufen: 8 Bit (1 Byte)
    • True Color (RGB): 24 Bit (3 Byte)
    • CMYK (Druck): 32 Bit (4 Byte)

Formeln

1. Umrechnung in Inch

Länge [in] = Länge [cm] / 2,54

2. Berechnung der Pixel pro Seite

Pixel = Länge [in] * DPI

3. Gesamtzahl der Pixel

Gesamtpixel = Breite [px] * Höhe [px]

4. Unkomprimierte Dateigröße

Größe [Bit] = Gesamtpixel * Farbtiefe [Bit]

Anschließend Umrechnung in Byte ( / 8), KB ( / 1024), MB ( / 1024).

Beispielrechnung

Ein Foto im Format 10 cm x 15 cm wird mit 300 DPI als True Color (24 Bit) gescannt. Wie groß ist die unkomprimierte Bilddatei in Megabyte (MB)?

  1. Breite in Inch: 10 cm / 2,54 = 3,937 in
  2. Höhe in Inch: 15 cm / 2,54 = 5,906 in
  3. Pixel Breite: 3,937 in * 300 DPI = 1.181 px
  4. Pixel Höhe: 5,906 in * 300 DPI = 1.772 px
  5. Gesamtpixel: 1.181 px * 1.772 px = 2.092.732 px
  6. Dateigröße in Bit: 2.092.732 px * 24 Bit = 50.225.568 Bit
  7. In Byte: 50.225.568 Bit / 8 = 6.278.196 Byte
  8. In KB: 6.278.196 Byte / 1024 = 6.131,05 KB
  9. In MB: 6.131,05 KB / 1024 ≈ 5,98 MB
