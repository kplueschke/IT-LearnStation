Datenstrukturen

Eine Übersicht der wichtigsten grundlegenden Datenstrukturen: Arrays, Verkettete Listen, Stacks und Queues.

Arrays (Felder)

Ein Array ist die einfachste und am häufigsten verwendete Datenstruktur. Es speichert eine feste Anzahl von Elementen des gleichen Datentyps in einem zusammenhängenden Speicherblock.

  • Zugriff: Sehr schnell (O(1)), da auf jedes Element direkt über seinen Index zugegriffen werden kann (beginnend bei 0).
  • Größe: Bei statischen Arrays ist die Größe zur Kompilierzeit festgelegt und kann später nicht geändert werden. Dynamische Arrays (wie std::vector in C++ oder List in C#) können wachsen, erfordern aber beim Vergrößern das Kopieren aller Elemente.
  • Vorteile: Kompakt im Speicher, schneller wahlfreier Zugriff.
  • Nachteile: Einfügen/Löschen in der Mitte ist langsam, da nachfolgende Elemente verschoben werden müssen.

Verkettete Listen

Eine verkettete Liste besteht aus einzelnen Knoten (Nodes), die über den Speicher verteilt sein können. Jeder Knoten enthält die eigentlichen Daten sowie einen Zeiger (Referenz) auf den nächsten Knoten. Bei einer doppelt verketteten Liste gibt es auch einen Zeiger auf den vorherigen Knoten.

  • Zugriff: Langsam (O(n)), um auf das n-te Element zuzugreifen, muss man vom ersten Knoten (Head) an alle Elemente durchlaufen.
  • Größe: Dynamisch. Es können beliebig viele Knoten hinzugefügt werden, solange Speicherplatz verfügbar ist.
  • Vorteile: Sehr schnelles Einfügen und Löschen von Elementen (wenn die Position bekannt ist), da nur Zeiger umgebogen werden müssen. Es müssen keine Elemente verschoben werden.
  • Nachteile: Kein direkter Zugriff (Index), zusätzlicher Speicherbedarf für die Zeiger, Elemente liegen nicht hintereinander im Cache (schlechtere Cache-Lokalität als Arrays).

Stack (Stapel / Kellerspeicher)

Ein Stack ist eine abstrakte Datenstruktur, die nach dem LIFO-Prinzip (Last-In, First-Out) arbeitet. Man kann sich das wie einen Tellerstapel vorstellen: Das Element, das zuletzt daraufgelegt wurde, wird als Erstes wieder heruntergenommen.

Hauptoperationen:

  • push(element): Legt ein Element oben auf den Stack.
  • pop(): Entfernt das oberste Element und gibt es zurück.
  • peek() / top(): Gibt das oberste Element zurück, ohne es zu entfernen.

Anwendungsbeispiele: Rückgängig-Funktion (Undo) in Texteditoren, Auswerten von mathematischen Ausdrücken (UPN), Call-Stack bei Funktionsaufrufen im Programm (Speichern von Rücksprungadressen und lokalen Variablen).

Queue (Warteschlange)

Eine Queue ist eine abstrakte Datenstruktur, die nach dem FIFO-Prinzip (First-In, First-Out) arbeitet. Es funktioniert wie eine Warteschlange an der Supermarktkasse: Wer sich zuerst anstellt, wird auch als Erstes bedient.

Hauptoperationen:

  • enqueue(element) / push(): Fügt ein Element am Ende (Tail) der Schlange ein.
  • dequeue() / pop(): Entfernt das vorderste Element (Head) der Schlange und gibt es zurück.
  • front() / peek(): Gibt das vorderste Element zurück, ohne es zu entfernen.

Anwendungsbeispiele: Druckaufträge (Druckerwarteschlange), Task-Scheduling im Betriebssystem, asynchrone Nachrichtenverarbeitung (Message Queues).
