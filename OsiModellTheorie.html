Das OSI-Modell

Das Open Systems Interconnection Model: Die 7 Schichten der Netzwerkkommunikation.

Layer 7

Application (Anwendungsschicht)

PDU: Data / Data Stream

Schnittstelle zwischen dem Netzwerk und den Anwendungsprogrammen. Hier finden die eigentlichen Netzwerkanwendungen statt (z.B. Webbrowser, E-Mail-Client).

HTTP/HTTPS FTP SMTP/IMAP DNS
Layer 6

Presentation (Darstellungsschicht)

PDU: Data / Data Stream

Übersetzt Datenformate (z.B. ASCII in EBCDIC). Verantwortlich für Datenkompression und Verschlüsselung (TLS/SSL).

JPEG/PNG ASCII/UTF-8 TLS/SSL
Layer 5

Session (Sitzungsschicht)

PDU: Data / Data Stream

Aufbau, Verwaltung und Beendigung von Sitzungen (Sessions) zwischen zwei Systemen. Bietet Mechanismen für Checkpoints (Wiederaufsetzen nach Abbruch).

NetBIOS RPC PPTP
Layer 4

Transport (Transportschicht)

PDU: Segment (TCP) / Datagram (UDP)

End-zu-End-Kontrolle. Segmentierung von Datenströmen. Multiplexing (Zuordnung zu Ports). Wahlweiser zuverlässiger (TCP) oder unzuverlässiger (UDP) Transport.

TCP UDP Ports (z.B. 80, 443)
Layer 3

Network (Vermittlungsschicht)

PDU: Packet (Paket)

Logische Adressierung (IP-Adressen). Routing der Pakete durch verschiedene Netzwerke (Wegfindung).

IPv4/IPv6 ICMP (Ping) IPsec Gerät: Router / Layer-3-Switch
Layer 2

Data Link (Sicherungsschicht)

PDU: Frame (Rahmen)

Physische Adressierung (MAC-Adressen). Erkennung (und teils Behebung) von Übertragungsfehlern auf der physischen Schicht. Zugangskontrolle zum Medium (CSMA/CD).

Ethernet (IEEE 802.3) WLAN (IEEE 802.11) MAC-Adressen Gerät: Switch / Bridge
Layer 1

Physical (Bitübertragungsschicht)

PDU: Bit / Symbol

Übertragung unstrukturierter Bitströme über ein physikalisches Medium (Kabel, Funk, Licht). Definiert Spannungspegel, Pinbelegungen, Kabeltypen.

Kupfer (Twisted Pair) Glasfaser Funkwellen Gerät: Hub / Repeater / Kabel
